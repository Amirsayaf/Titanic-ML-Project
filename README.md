# Titanic Survival Prediction

A machine learning project that predicts passenger survival on the Titanic using a Random Forest classifier.

## Project Overview

The goal of this project is to build and evaluate a classification model using passenger-related features.

## Model

- Algorithm: Random Forest Classifier
- Library: Scikit-learn
- Task: Binary classification

## Results

| Metric | Score |
|---|---:|
| Training Accuracy | 85.53% |
| Test Accuracy | 83.24% |
| 5-Fold Cross-Validation Accuracy | 83.00% |

## Project Files

- "Titanick.ipynb" — Jupyter Notebook containing the machine learning workflow.
- "train-selected-columns.csv" — Training dataset.
- "test-selected-columns.csv" — Test dataset.
- ".gitignore" — Files excluded from Git tracking.

## Requirements

- Python
- pandas
- scikit-learn
- Jupyter Notebook

## How to Run

1. Install the required libraries:
   
   pip install pandas scikit-learn jupyter

2. Open "Titanick.ipynb" in Jupyter Notebook.

3. Run the notebook cells in order.
